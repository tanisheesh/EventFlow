# Deploying EventFlow

> **Live:** [https://eventflow-g2h5.onrender.com](https://eventflow-g2h5.onrender.com) · **Host:** Render · **Auto-deploy:** on push to `master`

For local development, see [SETUP.md](SETUP.md).

---

## 1. Production Topology & Resource Limits

| Component | Host / Service | Region & Runtime | Configured Limits / Quotas |
|---|---|---|---|
| EventFlow Web App | Render Web Service (`render.yaml`) | Oregon (`oregon`) · Python (`python start.py`) | Free plan · 512 MB RAM · sleeps after 15m idle (~30s cold start) |
| Database | Render Container Disk (SQLite) | Co-located (`sqlite:///eventhub.db`) | Ephemeral local disk · re-created + demo seeded on every boot |
| Reqly Collector | Render Web Service | [reqly-eventflow-collector.onrender.com](https://reqly-eventflow-collector.onrender.com) | Free tier · receives batched async telemetry (`reqly>=0.7.1`) |
| Reqly Dashboard | Render Web Service | [reqly-eventflow-dashboard.onrender.com](https://reqly-eventflow-dashboard.onrender.com) | Public read-only dashboard linked in Admin nav & footer |

## 2. Production Environment Variables

Configure all secrets in the Render dashboard or `render.yaml` Blueprint (never commit real secrets). Full key list is in [`.env.example`](../.env.example).

| Variable | Required | Host Location (`render.yaml`) | Rotation / Sensitivity |
|---|---|---|---|
| `SECRET_KEY` | ✅ | Generated by Blueprint (`generateValue: true`) | High — rotate forces re-login of active Flask cookie sessions |
| `FLASK_ENV` | ✅ | `render.yaml` (`production`) | Low |
| `DATABASE_URL` | ✅ | `render.yaml` (`sqlite:///eventhub.db`) | Medium (or High if switched to external PostgreSQL URI) |
| `PORT` | ✅ | `render.yaml` (`5000`) | Low |
| `REQLY_COLLECTOR_URL` | ❌ | `render.yaml` (`https://reqly-eventflow-collector.onrender.com`) | Low |
| `REQLY_API_KEY` | ❌ | Render Dashboard (`sync: false`) — collector's `REQLY_INGEST_KEY` | High — secret token |
| `REQLY_ENVIRONMENT` | ❌ | `render.yaml` (`production`) | Low |
| `REQLY_CONSUMER_SALT` | ❌ | Generated by Blueprint (`generateValue: true`) | High — hashes user IDs before telemetry leaves app |
| `REQLY_DASHBOARD_URL` | ❌ | `render.yaml` (`https://reqly-eventflow-dashboard.onrender.com`) | Low |

Render automatically injects `RENDER_GIT_COMMIT` on every deploy, which the Reqly SDK attaches as the release identifier.

> Changing an environment variable in Render does **not** update a running container — trigger a manual deploy or restart after updating env vars.

## 3. First-Time Deploy

### Option A: Render (Blueprint)

1. Open [dashboard.render.com](https://dashboard.render.com) → **New** → **Blueprint** → connect `tanisheesh/EventFlow` (`master` branch). Render loads [`render.yaml`](../render.yaml).
2. Confirm build command: `pip install -r requirements.txt`
3. Confirm start command: `python start.py`
4. Enter `REQLY_API_KEY` when prompted (or leave unset to run fail-open without telemetry) and deploy.

### Option B: Docker / Self-Host

The repository does not currently ship a `Dockerfile`, because Render runs Python natively via `render.yaml`. To self-host EventFlow inside a container using `gunicorn` (already included in `requirements.txt`):

```bash
# Example self-hosted container launch using python:3.12-slim
docker run -d --name eventflow --restart unless-stopped \
  -p 5000:5000 \
  --env-file .env \
  -v eventflow-instance:/app/instance \
  -w /app python:3.12-slim \
  sh -c "pip install --no-cache-dir -r requirements.txt && python -c 'from app import app, db; app.app_context().push(); db.create_all()' && python create_admin_users.py && gunicorn -w 1 -b 0.0.0.0:5000 app:app"
```

Mount your cloned `EventFlow` directory into `/app` (`-v "$(pwd):/app"`) or bake a custom image with `COPY . /app`. Keep `-w 1` when backed by local SQLite to avoid multi-process write lock contention, and mount `/app/instance` to persist `eventhub.db` across container restarts.

## 4. Database Initialization & Migrations

EventFlow does not use an external migration tool (`flask-migrate` was removed in `c49c935`).

- **Startup bootstrap (`start.py`):** Runs `db.create_all()` to create missing tables, runs an idempotent column check adding `event.organizer_id` if absent, and seeds the three demo accounts via `create_admin_users()`.
- **Schema changes:** On ephemeral Render free-tier storage, the SQLite file is recreated fresh on every deploy. When running against a persistent volume or PostgreSQL in v2, apply additive nullable columns first (`ALTER TABLE`) before deploying code that reads/writes them.

## 6. Post-Deploy Smoke Verification

Run immediately after a production deploy (allow ~30s for Render free-tier cold start):

```bash
# 1. Home page returns 200
curl -fsS -o /dev/null -w "%{http_code}\n" https://eventflow-g2h5.onrender.com/

# 2. Protected organizer route fails closed (302 redirect to /login)
curl -s -o /dev/null -w "%{http_code}\n" https://eventflow-g2h5.onrender.com/dashboard

# 3. Inspect response headers & TLS status
curl -sI https://eventflow-g2h5.onrender.com/
```

Interactive checklist:
- [ ] `https://eventflow-g2h5.onrender.com` loads cleanly on mobile (`375px`) and desktop (`1280px`)
- [ ] All three demo accounts (`admin@eventhub.com`, `organizer@eventhub.com`, `buyer@eventhub.com`) log in
- [ ] Organizer creates an event + ticket tier; attendee books and cancels a ticket with accurate stock sync
- [ ] Administrator **Metrics** nav link opens [reqly-eventflow-dashboard.onrender.com](https://reqly-eventflow-dashboard.onrender.com) showing traffic tagged with the new `RENDER_GIT_COMMIT`

## 7. Rollback Procedure

| Layer | Rollback Action |
|---|---|
| **Render** | Dashboard → **EventFlow** → **Events** → select last healthy deploy → **Rollback** |
| **Database** | Render free-tier SQLite resets cleanly on boot; nothing to migrate backward |

> Always record any manual rollback (target commit SHA and reason) in a commit or PR so the next push to `master` does not silently re-ship the broken change.

## 8. Incident & Quota Runbooks

| Incident | Immediate Action |
|---|---|
| **502 / slow initial response (~30s)** | Render free instance woke from 15m idle sleep; retry request and verify `start.py` bound `0.0.0.0:$PORT` in Render Logs |
| **SQLite `database is locked` (self-hosted)** | Ensure single-worker WSGI (`-w 1`) or migrate `DATABASE_URL` to PostgreSQL |
| **Reqly collector down or returning errors** | Confirm EventFlow still serves `200` (Reqly is fail-open); inspect collector logs on Render and verify `REQLY_API_KEY` matches `REQLY_INGEST_KEY` |
| **Suspected secret leak (`SECRET_KEY` / `REQLY_API_KEY`)** | Rotate key in Render Dashboard → trigger Manual Deploy → confirm Gitleaks (`secret-scan.yml`) and GitHub Secret Scanning show 0 open alerts |
